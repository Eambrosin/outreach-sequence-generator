# v2.1.0 — Qualification-First Adaptive Outreach Intelligence

## Release Summary

Version 2.1.0 strengthens ENGAGE as the downstream execution layer of the Commercial Intelligence portfolio.

The release focuses on preserving upstream qualification context while generating adaptive, multilingual outreach sequences.

## Highlights

- stronger IDENTIFY / PRIORITIZE handoff compatibility
- qualification-aware outreach strategy
- Buyer Access and Sales Motion context
- priority-based cadence
- public-channel-aware execution
- multilingual outreach generation
- qualification-first messaging
- account intelligence workspace
- territory and field-sales context
- field-day planning
- visit-feedback loop
- deterministic generation path
- optional AI-assisted copy
- automated tests and GitHub Actions CI
- full-history secret scanning

## Commercial Design Principles

The release keeps internal commercial intelligence separate from prospect-facing communication.

It does not convert:

- internal scores into external claims
- missing evidence into certainty
- account priority into purchase intent
- unverified contacts into confirmed decision-makers

## Portfolio Workflow

```text
IDENTIFY → PRIORITIZE → ENGAGE
IDENTIFY / Partner Universe → PARTNER → ENGAGE
```
